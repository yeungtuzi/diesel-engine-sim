# 四冲程柴油机 · 高精度 3D 交互仿真系统

一个基于 **Three.js**（PBR 物理渲染）的网页端四冲程柴油机交互仿真。完整呈现机体、曲柄连杆、配气、燃油、润滑、冷却、进排气等全部核心零部件，并按精确相位驱动「吸气 → 压缩 → 做功 → 排气」循环。

## 快速开始

本项目使用 ES Module + import map，需通过 HTTP 服务访问（直接双击 index.html 会因跨域无法加载模块）。任选其一：

    # 方式一：Python（macOS / Linux 自带）
    cd diesel-engine-sim
    python3 -m http.server 8080

    # 方式二：Node
    npx serve .

浏览器打开 http://localhost:8080/ 即可。无需安装依赖，无需联网（Three.js 已内置在 js/vendor/）。

## 功能特性

- 全尺寸可拆解级建模：4 缸直列柴油机（缸径 92mm、行程 110mm、缸心距 112mm），含 40+ 类零件、350+ 网格，悬停可查看全部信息。
- 精确四冲程相位：点火顺序 1-3-4-2；配气相位（进气门 -15°~220°、排气门 495°~735°、喷油 348°~366°）与曲轴转角严格同步；实时显示曲轴转角与当前冲程。
- PBR 渲染：差异化材质（铸铁 / 铝合金 / 锻钢 / 铜铅轴瓦 / 橡胶 / 不锈钢 / 弹簧钢），HDR 环境反射 + ACES 色调映射，半透明剖视与半透明外壳。
- 流体示意：冷却液与润滑油沿流道以粒子形式流动，流速随转速动态变化。
- 状态面板：转速、水温、油压、曲轴转角、当前冲程、各缸冲程、喷油指示。
- 60fps 流畅动画：运动学闭式解驱动，活塞/气门/摇臂/凸轮/飞轮/水泵/风扇/涡轮实时联动。

## 技术要点

- 运动学（js/kinematics.js）：曲柄滑块机构闭式解 pinY = r·cosβ + √(l² − r²·sin²β)；凸轮升程用正弦加减速型线；配气相位由各缸「吸气上止点」偏移量（CYL.cycleOffset = [0,540,180,360]）与曲柄夹角（throwOffset = [0,180,180,0]）共同决定。
- 坐标系：Y 为气缸轴线（向上）、Z 为曲轴轴线（1→4 缸）、X 为横向；剖切面 X=0（保留 X<0 侧）。

## 嵌入与脚本控制

页面暴露全局 window.dieselSim 对象，便于嵌入网页或二次开发：

    dieselSim.setRPM(2000);       // 设置转速
    dieselSim.setPlaying(false);  // 暂停
    dieselSim.setSection(true);   // 剖视
    dieselSim.setExplode(true);   // 分解视图
    dieselSim.setView('iso');     // 视角预设
    dieselSim.getState();         // { angle, stroke, rpm, coolant, oil, ... }
